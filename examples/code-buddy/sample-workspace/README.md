# sample-workspace

A throwaway directory for the code-buddy walkthrough (see [`../README.md`](../README.md)).
`Geometry.swift` has a handful of public declarations with no doc comments — a small, low-risk
task for the model to work on.

Don't run code-buddy against this copy directly (it's inside the `locallm` git repo, so a
`git diff` here would be noisy and `git checkout` would fight the parent repo). Copy it somewhere
else and `git init` there — the walkthrough shows how.
