# JevDK

JevDK now lives in its own project: **[github.com/ancientcomputing/jevdk](https://github.com/ancientcomputing/jevdk)**.
Source, releases and issues are there, not here.

JevDK is a Mac app for **decision questions**: try out the questions your app will ask a decision model
(a "decider"), see how it answers on a model on your Mac and on hosted Jev side by side, score a batch
against your marked answers, calibrate, and export the tested setup. It is the reference app for the SDK's
decision API (`lab.decide`).

- **Download:** [the latest JevDK release](https://github.com/ancientcomputing/jevdk/releases/latest)
  (macOS 27, Apple silicon, signed and notarized; includes `jev-serve`).
- **Source:** [ancientcomputing/jevdk](https://github.com/ancientcomputing/jevdk).
- **Developer's guide:** [thisbrain.ai/locallm/jdk-guide.html](https://thisbrain.ai/locallm/jdk-guide.html), with
  screenshots: what a decider is, when to use one, and the workflow from writing questions to shipping them.
- **New to decision models?** [Decision models (Jev) in your app](https://thisbrain.ai/locallm/jev.html).
- **In the SDK:** the decision API is in the [decision models guide](../../docs/decision-models.md).
